# Credit Risk Portfolio Website

Recruiter-facing case study for the Credit Risk Analytics & ML Scoring project.

The first viewport introduces the project, followed immediately by the actual six-page Power BI dashboard. The remaining sections explain business findings, ML validation, governance, and links to reproducible evidence.

## Local Preview

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
```

The site is intentionally self-contained: dashboard images and the PDF export are stored in `public/` and no external data service is required.
