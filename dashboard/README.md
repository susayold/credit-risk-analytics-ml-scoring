# Power BI Dashboard

This folder contains the primary business deliverable for the project.

## Files

- `dashboard.pbix`: editable six-page Power BI report
- `dashboard.pdf`: complete exported report for reviewers without Power BI Desktop
- `screenshots/dashboard_page_01.png` to `dashboard_page_06.png`: web-ready page exports

## Page Flow

1. Portfolio Overview
2. Customer Profile
3. Loan & Affordability
4. Credit History
5. Payment Behavior
6. Risk Segmentation

The dashboard's rule-based segments are designed for descriptive monitoring and review prioritization. They are separate from the LightGBM score bands reported in Step 8.
